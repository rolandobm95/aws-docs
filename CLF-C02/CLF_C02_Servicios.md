# Recomendación de estudio

## Alta prioridad
- Modelo de responsabilidad compartida
- IAM, usuario root y MFA
- Amazon EC2 y modelos de compra (On-Demand, Reserved, Spot, Savings Plans)
- Amazon S3 y clases de almacenamiento
- Amazon VPC, grupos de seguridad y NACL
- Regiones, zonas de disponibilidad y ubicaciones de borde
- Amazon RDS, Aurora y DynamoDB
- AWS Lambda
- Pilares del Well-Architected Framework
- AWS Support, Trusted Advisor y Organizations (facturación consolidada)
- AWS Budgets, Cost Explorer y Pricing Calculator

## Prioridad media
- CloudWatch, CloudTrail y Config
- KMS, ACM, Secrets Manager, Shield y WAF
- GuardDuty, Inspector, Macie y Security Hub
- ECS, EKS y Fargate
- Route 53, CloudFront, VPN y Direct Connect
- SNS, SQS y EventBridge
- CloudFormation y Elastic Beanstalk
- EBS, EFS, FSx y Storage Gateway
- Cloud Adoption Framework (CAF)

## Prioridad complementaria
- Servicios de IA/ML (Rekognition, Polly, Lex, Transcribe, Translate, Comprehend, Textract, SageMaker AI, Amazon Q)
- Analítica (Athena, Glue, Kinesis, Quick, Redshift, EMR, OpenSearch)
- IoT Core, WorkSpaces, AppStream 2.0, Connect y SES
- Servicios de migración (DMS, SCT, MGN, Migration Hub)
