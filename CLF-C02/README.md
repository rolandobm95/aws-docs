# Guía de Estudio - AWS Certified Cloud Practitioner (CLF-C02)
Plan de preparación estructurado para aprobar el examen AWS Certified Cloud Practitioner (CLF-C02). Esta guía organiza los 4 dominios del examen con preguntas de práctica, notas de repaso y recursos oficiales.

---

## Datos del Examen
Información basada en la [guía oficial del examen CLF-C02](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html).

| Característica | Detalle |
|----------------|---------|
| Perfil objetivo | Hasta 6 meses de exposición a la nube de AWS, sin importar el rol |
| Tipos de pregunta | Opción múltiple (1 correcta de 4) y respuesta múltiple (2 o más correctas de 5 o más) |
| Preguntas puntuadas | 50 |
| Preguntas no puntuadas | 15 (no se identifican en el examen) |
| Calificación | Escala de 100 a 1.000, con 700 como puntaje mínimo para aprobar |
| Modelo de puntaje | Compensatorio: se aprueba el examen completo, no cada sección |
| Penalización | Ninguna por adivinar; las preguntas sin responder cuentan como incorrectas |

**Fuera del alcance del candidato:** programar, diseñar arquitecturas de nube, resolver problemas, implementar y realizar pruebas de carga y rendimiento.

| Dominio | Peso |
|---------|------|

| Dominio 3 - Tecnología y Servicios de la Nube | 34% |
