# Semana 8 - Tareas 4.1 a 4.3 Precios, facturación y soporte

## Objetivos
-   Comparar modelos de precios de AWS.
-   Entender recursos de facturación, presupuesto y administración de costos.
-   Identificar recursos técnicos y planes de AWS Support.

## - Módulo 1 - Modelos de precios (Tarea 4.1)

### Temas
-   Modelos de compra de cómputo: On-Demand, Reserved Instances, Spot Instances, Savings Plans, Dedicated Hosts, Dedicated Instances y Capacity Reservations
-   Flexibilidad de las Reserved Instances (Standard vs. Convertible)
-   Comportamiento de las Reserved Instances en AWS Organizations (compartir descuentos)
-   Costos de transferencia de datos: entrada gratuita, salida con costo, entre Regiones y dentro de la misma Región
-   Precios de almacenamiento y niveles (clases de S3, tipos de EBS)
-   Capa gratuita de AWS (Free Tier)
-   Principios de precios: pago por uso, pagar menos al reservar y pagar menos al usar más

### Laboratorio
-   Comparar el precio de una instancia en On-Demand, Spot y Savings Plans.
-   Estimar el costo de transferencia de datos de una aplicación.

### Documentación oficial
-   [Precios de Amazon EC2](https://aws.amazon.com/ec2/pricing/)
-   [Savings Plans](https://docs.aws.amazon.com/savingsplans/)
-   [Precios de Amazon S3](https://aws.amazon.com/s3/pricing/)
-   [Capa gratuita de AWS](https://aws.amazon.com/free/)

## - Módulo 2 - Facturación, presupuestos y administración de costos (Tarea 4.2)

### Temas
-   AWS Billing and Cost Management
-   AWS Budgets (alertas y acciones)
-   AWS Cost Explorer (análisis y pronóstico)
-   AWS Pricing Calculator (estimaciones)
-   AWS Cost and Usage Report (CUR)
-   AWS Organizations: facturación consolidada y asignación de costos
-   Etiquetas de asignación de costos: definidas por AWS y definidas por el usuario
-   AWS Cost Anomaly Detection
-   AWS Marketplace (costos y gobernanza)

### Laboratorio
-   Crear un presupuesto mensual con alerta por correo.
-   Activar una etiqueta de asignación de costos y verla en Cost Explorer.

### Documentación oficial
-   [AWS Budgets](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html)
-   [AWS Cost Explorer](https://docs.aws.amazon.com/cost-management/latest/userguide/ce-what-is.html)
-   [AWS Pricing Calculator](https://docs.aws.amazon.com/pricing-calculator/)
-   [Facturación consolidada](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/consolidated-billing.html)
-   [Etiquetas de asignación de costos](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html)

## - Módulo 3 - Recursos técnicos y planes de AWS Support (Tarea 4.3)

### Temas
-   Planes de AWS Support según la guía vigente: Basic Support, Business Support+, Enterprise Support y Unified Operations (planes históricos: Developer, Business y Enterprise On-Ramp)
-   Technical Account Manager (TAM)
-   AWS Support Center
-   AWS Trusted Advisor (costo, rendimiento, seguridad, tolerancia a fallos, límites de servicio)
-   AWS Health Dashboard y AWS Health API
-   AWS Trust and Safety (reporte de abuso)
-   AWS Partner Network (APN), ISVs e integradores de sistemas
-   AWS Marketplace
-   Beneficios de ser Partner: capacitación, eventos y descuentos por volumen
-   AWS Professional Services y arquitectos de soluciones
-   Recursos: whitepapers, blogs, AWS Prescriptive Guidance, AWS Knowledge Center y AWS re:Post

### Laboratorio
-   Comparar los planes de AWS Support en la página oficial.
-   Revisar las recomendaciones de Trusted Advisor.
-   Explorar AWS re:Post y el Knowledge Center.

### Documentación oficial
-   [Planes de AWS Support](https://aws.amazon.com/premiumsupport/plans/)
-   [AWS Trusted Advisor](https://docs.aws.amazon.com/awssupport/latest/user/trusted-advisor.html)
-   [AWS Health](https://docs.aws.amazon.com/health/)
-   [AWS Prescriptive Guidance](https://aws.amazon.com/prescriptive-guidance/)
-   [AWS re:Post](https://repost.aws/)
-   [AWS Partner Network](https://aws.amazon.com/partners/)
