# Semana 1 - Tareas 1.1 y 1.2 Beneficios y principios de diseño de la nube de AWS

## Objetivos
-   Definir la propuesta de valor de la nube de AWS.
-   Explicar alta disponibilidad, elasticidad y agilidad.
-   Identificar los seis pilares del AWS Well-Architected Framework.

## - Módulo 1 - Propuesta de valor de la nube (Tarea 1.1)

### Temas
-   Computación en la nube: modelo de pago por uso
-   Seis ventajas de la nube (cambiar CapEx por OpEx, economías de escala, dejar de adivinar la capacidad, velocidad y agilidad, dejar de gastar en centros de datos, alcance global)
-   Infraestructura global (velocidad de despliegue y alcance global)
-   Alta disponibilidad, elasticidad, escalabilidad y agilidad
-   Tolerancia a fallos vs. alta disponibilidad
-   Modelos de servicio: IaaS, PaaS, SaaS
-   Modelos de despliegue: nube, híbrido, on-premises

### Laboratorio
-   Crear una cuenta AWS y explorar la consola de administración.
-   Lanzar una instancia EC2 y comprobar el tiempo de aprovisionamiento.
-   Terminar la instancia y observar que el cobro se detiene.

### Documentación oficial
-   [¿Qué es la computación en la nube?](https://aws.amazon.com/what-is-cloud-computing/)
-   [Tipos de computación en la nube](https://aws.amazon.com/types-of-cloud-computing/)
-   [Whitepaper: Overview of Amazon Web Services](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html)

# Semana 2 - Tareas 1.3 y 1.4 Migración y economía de la nube

## Objetivos
-   Comprender estrategias y recursos de migración a AWS.
-   Entender el AWS Cloud Adoption Framework (AWS CAF).
-   Explicar conceptos de economía de la nube.

## - Módulo 3 - Migración a la nube (Tarea 1.3)

### Temas
-   Estrategias de migración (las 7 R: retire, retain, rehost, relocate, repurchase, replatform, refactor)
-   AWS Cloud Adoption Framework (AWS CAF) y sus perspectivas
-   Beneficios del CAF: reducción de riesgo de negocio, mejor desempeño ESG, mayores ingresos y mayor eficiencia operativa
-   AWS Application Discovery Service
-   AWS Application Migration Service
-   AWS Migration Hub y Migration Evaluator
-   AWS Database Migration Service (DMS) y Schema Conversion Tool (SCT)
-   Replicación de bases de datos como estrategia de migración
-   AWS Snow Family (transferencia física de datos)

### Laboratorio
-   Revisar las perspectivas del CAF y asignar una a cada necesidad de una empresa ficticia.
-   Explorar la consola de AWS DMS y revisar el flujo de una tarea de migración.

### Documentación oficial
-   [AWS Cloud Adoption Framework](https://docs.aws.amazon.com/whitepapers/latest/overview-aws-cloud-adoption-framework/overview-aws-cloud-adoption-framework.html)
-   [Estrategias de migración (7 R)](https://docs.aws.amazon.com/prescriptive-guidance/latest/large-migration-guide/migration-strategies.html)
-   [AWS Migration Hub](https://docs.aws.amazon.com/migrationhub/)
-   [AWS DMS](https://docs.aws.amazon.com/dms/)

------------------------------------------------------------------------

## - Módulo 4 - Economía de la nube (Tarea 1.4)

### Temas
-   Costos fijos vs. costos variables
-   Costos asociados a entornos on-premises (hardware, energía, espacio, personal, refrescos tecnológicos)
-   Costo total de propiedad (TCO)
-   Licenciamiento: BYOL vs. licencias incluidas
-   AWS License Manager
-   Rightsizing (dimensionamiento correcto)
-   Beneficios de la automatización
-   Economías de escala

### Laboratorio
-   Comparar el costo de un servidor on-premises frente a EC2 con AWS Pricing Calculator.
-   Revisar recomendaciones de rightsizing en AWS Compute Optimizer.

### Documentación oficial
-   [AWS Pricing Calculator](https://docs.aws.amazon.com/pricing-calculator/)
-   [AWS Compute Optimizer](https://docs.aws.amazon.com/compute-optimizer/)
-   [AWS License Manager](https://docs.aws.amazon.com/license-manager/)
-   [Economía de la nube](https://aws.amazon.com/economics/)
